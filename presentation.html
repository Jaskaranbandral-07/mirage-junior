Problem Definition & Motivation • Slide 2 of 8

The Core Problem Statement: Why Traditional Defenses Fail

🚨 Why Traditional Firewalls & IDS Fail
  • Firewalls & Signature IDS are Reactive: They only match known attack signatures. Novel zero-day payloads pass completely undetected.
  • Zero Internal Lateral Movement Visibility: Once an attacker breaches the perimeter boundary (via phishing or leaked VPN credentials), firewalls provide zero internal visibility.
  • Alert Fatigue: SOC analysts receive 10,000+ noisy alerts per day with high false-positive rates, burying real critical intrusions.
  • Attacker Asymmetry: The defender must protect 100% of attack surfaces, while an attacker only needs a single misconfiguration to compromise the entire network.
🎯 Project Objective (Why MIRAGE Junior?)
  • Flip the Asymmetry: Deploy high-enticement decoy servers across unused network spaces. Because legitimate users have no reason to touch decoys, every interaction is 100% malicious with zero false positives.
  • Sub-Second Threat Triage: Quantify attacker severity with mathematical weightings and decay rather than blunt binary blocks.
  • Automated Containment: Dynamically sever network access at 25 threat points before lateral expansion occurs.
  • Mobile SOC Reach: Push critical incident alerts directly to security admins via Telegram bots.
Architecture & Solution • Slide 3 of 8

Proposed Solution: 4-Tier Autonomous Deception Grid

Tier 1: Deception Decoy Grid
Multi-protocol low-interaction honeypots (SSH, HTTP, FTP, Telnet, MySQL) emulating authentic server banners while strictly sandboxing commands to prevent host compromise.
Tier 2: Ingestion & Telemetry Bus
Captures raw socket handshakes, parses HTTP payloads and login attempts, normalizes into JSON envelopes, and enriches with GeoIP location and MITRE ATT&CK TTP mapping.
Tier 3: Analytics & Containment Engine
Calculates behavioral threat scores in real-time with exponential threat decay. Triggers cross-platform OS firewall isolation (netsh/iptables) the instant score reaches 25 points.
Tier 4: Real-Time SOC Command Center
Next.js 14 and Tailwind CSS dashboard with dark cyber glassmorphism, 10-per-page paginated attack feeds, attacker timeline replays, and instant mobile Telegram alerts.

Mathematical Modeling • Slide 5 of 8

Behavioral Threat Scoring & Mathematical Decay Model

📐 The Threat Decay Formula
Score(t) = Score₀ · e^( -λ · Δt )
  • Score₀: Accumulated raw behavioral threat points from attack events.
  • λ (Decay Constant): ln(2) / Half-Life (configured for 3600s).
  • Δt: Elapsed time in seconds since the attacker's last logged interaction.
  • Why Decay? Transient internet scanners probe once and leave; their scores decay naturally to 0. Persistent attackers sustain rapid actions and reach quarantine.
⚡ Action-Based Threat Weights Matrix
  • Port Scan / Decoy Probe (+5 pts): Low Risk (reconnaissance scan).
  • Directory Traversal / Auth Probe (+15 pts): Medium Risk (path navigation / brute probe).
  • SQL Injection / RCE Exploitation (+20 pts): High Risk (direct weaponized exploit payload).
  • Sustained Brute Force / Burst (+30 pts): Critical Risk (automated dictionary attack).
  • Honeytoken File Access (.env / .sql) (+40 pts): Severe Risk (guaranteed breach tripwire).
Autonomous Response • Slide 6 of 8

Zero-Delay Auto-Quarantine & Mobile Telegram Alerts

🛡️ 25-Point Auto-Quarantine Threshold
  • Why 25 Points? Calibrated to prevent false blocks from single casual port pings (5 pts), while instantly neutralizing deliberate multi-step attacks.
  • Trigger Combinations:
    • 2 Directory Traversals: 15 + 15 = 30 pts ≥ 25 ➔ QUARANTINE
    • 1 SQL Injection + 1 Probe: 20 + 5 = 25 pts ≥ 25 ➔ QUARANTINE
    • 1 Brute-Force Burst: 30 pts ≥ 25 ➔ IMMEDIATE QUARANTINE
  • Sub-50ms Reaction Speed: Executes in < 50ms compared to the 15–45 minute average response time of traditional human SOC teams.
  • Cross-Platform OS Enforcement:
    Linux: iptables -I INPUT -s <ip> -j DROP
    Windows: netsh advfirewall firewall add rule name="MIRAGE-BLOCK" dir=in action=block remoteip=<ip>
📱 Instant Telegram SOC Push Notifications
  • Mobile SOC Reach: Security admins are not stationed at a terminal 24/7. Push notifications deliver instant situational awareness to smartphones anywhere.
  • Asynchronous & Non-Blocking: Dispatched via background worker queue; network latency or bot delays never degrade decoy capture responsiveness.
  • Rich Incident Payload Contents:
    • 🚨 Severity Banner: CRITICAL / QUARANTINE
    • 🌐 Attacker IP & GeoIP Origin Country
    • 🎯 Targeted Service & Exploit String
    • 📈 Real-Time Threat Score vs 25 Threshold
    • 🛡️ Confirmation of Applied Firewall DROP Rule
  • Zero-Secrets Git Security: Bot tokens & Chat IDs stored strictly in local .env files; never committed to public version control.
