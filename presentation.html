Problem Definition & Motivation

Slide 2: The Core Problem Statement

🚨 Why Traditional Defenses Fail
  • Firewalls & Signature IDS are Reactive: They only match known attack signatures. Novel zero-day payloads pass completely undetected.
  • Zero Internal Lateral Movement Visibility: Once an attacker breaches the perimeter boundary (via phishing or leaked VPN credentials), firewalls provide zero internal visibility.
  • Alert Fatigue: SOC analysts receive 10,000+ noisy alerts per day, burying real critical intrusions.
  • Attacker Asymmetry: The defender must protect 100% of the surface area, while the attacker only needs a single misconfiguration to win.
🎯 Project Objective (Why MIRAGE Junior?)
  • Flip the Asymmetry: Deploy high-enticement decoy servers across unused network spaces. Because legitimate users have no reason to touch decoys, every interaction is 100% malicious with zero false positives.
  • Sub-Second Threat Triage: Quantify attacker severity with mathematical weightings and decay rather than blunt binary blocks.
  • Automated Containment: Dynamically sever network access at 25 threat points before lateral expansion occurs.
  • Mobile SOC Reach: Push critical incident alerts directly to security admins via Telegram bots.
System Philosophy

Deception-Driven Active Cyber Defense

1. Enticement & Decoys
Emulate high-value network services (SSH, Web Admin, FTP, Telnet, MySQL) with believable banners and interactive protocol handshakes to trap adversaries without risking production assets.
2. Mathematical Scoring
Assign granular threat weights to adversarial behaviors (directory traversal = 15 pts, SQL injection = 20 pts, brute force = 30 pts) with time-decay mathematics.
3. Autonomous Quarantine
Enforce immediate firewall quarantine (iptables / netsh) the instant an IP's cumulative score hits 25 points, dispatching forensic snapshots to Telegram.
Core Principle: "Any touch on an internal deception sensor constitutes hostile intent with zero false positives."
System Architecture

4-Tier Decoupled Cyber Defense Architecture

🏗️ Architecture Breakdown
  • Tier 1 — Deception Decoy Grid: Lightweight Python daemon emulating 5 distinct attack vectors with safe containment sandboxing.
  • Tier 2 — Ingestion & Telemetry Bus: Normalizes disparate logs into structured JSON envelopes with GeoIP enrichment and MITRE ATT&CK mapping.
  • Tier 3 — Analytics & Quarantine Engine: Continuous score calculation, sliding window evaluator, and host firewall executor.
  • Tier 4 — Modern Next.js Command Hub: Real-time visualization dashboard featuring dark cyber glassmorphism, 10-per-page paginated tables, and live telemetry.

  • Frontend Dashboard: Next.js 14, React, Tailwind CSS, Lucide Icons, Glassmorphism UI.
  • Containment: Dynamic iptables (Linux) & netsh advfirewall (Windows) rules.
  • Mobile Alerts: Telegram Bot API via asynchronous webhook HTTPS pipeline.

Mathematical Modeling

Scoring Engine & Exponential Threat Decay

📐 The Mathematical Threat Decay Formula
Score(t) = Score₀ · e^( -λ · Δt )
  • Score₀: Accumulated raw threat points from malicious events.
  • λ (Decay Constant): ln(2) / Half-Life (configured for 3600s).
  • Δt: Elapsed time in seconds since the last detected event.
  • Why Decay? Port scanners probe once and leave; aggressive persistent attackers sustain continuous high scores.
⚡ Behavior Event Point Weights
Attack Pattern Points Severity
Port Scan / Probe +5 pts Low
Directory Traversal / Auth Probe +15 pts Medium
SQL Injection (SQLi) / RCE +20 pts High
Sustained Brute-Force / Exploit +30 pts Critical
Autonomous Defense Execution

Zero-Delay Auto-Quarantine at 25 Points

🛡️ Why the 25-Point Threshold?
  • Configured & Hardened: Calibrated specifically to eliminate attacker dwelling time while tolerating stray single pings.
  • Trigger Scenarios:
    • 2 Directory Traversal hits (15 + 15 = 30 pts ≥ 25) ➔ QUARANTINED
    • 1 SQLi + 1 Port Probe (20 + 5 = 25 pts ≥ 25) ➔ QUARANTINED
    • 1 Brute-force burst (30 pts ≥ 25) ➔ QUARANTINED
  • Zero Human Latency: Traditional SOC triage takes 15–45 minutes. MIRAGE Junior executes isolation in under 50 milliseconds.
💻 Cross-Platform Firewall Execution

Linux Kernel iptables Rule:

iptables -I INPUT -s <attacker_ip> -j DROP

Windows Defender netsh Rule:

netsh advfirewall firewall add rule name="MIRAGE-BLOCK" dir=in action=block remoteip=<attacker_ip>

Quarantine events are logged in the ACID database and immediately broadcasted to the live WebSocket feed.

Defensive Hardening

Operational Security & Zero-Secret Architecture

🔒 Zero-Secrets Repository Policy
  • Environment Isolation: All sensitive credentials (Telegram bot tokens, admin keys, database paths) are isolated in local `.env` files.
  • Strict .gitignore & Git Guardian Protection: Prevents automated secret scanners and public token revocation.
  • Safe Defaults: If the bot token is omitted, the engine logs warnings cleanly without crashing or interrupting decoy capture.
🛡️ Decoy Sandboxing & Safety
  • Low-Interaction Boundaries: Decoys never execute attacker shell commands on the host OS. Command inputs are parsed as string telemetry only.
  • Rate-Limiting Protection: Ingestion queues drop packet floods to defend against denial-of-service against the honeypot listener itself.
  • ACID Reliability: Embedded SQLite engine with WAL (Write-Ahead Logging) mode to prevent database locks during multi-threaded attack spikes.
