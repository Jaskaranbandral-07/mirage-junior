📋 How to get Firebase config (free, 3 minutes):

  1. Go to console.firebase.google.com → Create a project (name it anything, e.g. "mirage-tracker")
  2. Disable Google Analytics when asked (not needed) → Create
  3. Click the Web icon </> → Register app (any nickname) → Copy the firebaseConfig JSON object shown
  4. Go to Build → Realtime Database → Create Database → choose any location → Start in Test mode → Enable
  5. Paste the config JSON above ↑
  6. Share this same config with your partner so they paste it too!
